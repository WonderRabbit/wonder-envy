# 18. AI 도구 설치·설정·상세 운영 문서

작성일: 2026-09-11. [조사](../../research/2026-09-11-ai-tooling.md)의 추천 5종 QMD·Repomix·Sidekick.nvim·LLM·Promptfoo를 설치한다. Serena·Ollama·MCPorter 등의 조건부 후보는 이번 범위에 포함하지 않는다. 사용자는 설치와 상세 설명서를 요청했으며 기존 세션의 계획·결과 커밋 및 푸시 요청을 이어 적용한다.

## 운영 기준

- macOS Apple Silicon, Fish 기본 셸, nvm Node·pyenv Python·uv·LazyVim을 재사용한다.
- npm 공유 설치는 한 담당자가 직렬 수행한다. Python 설치와 Neovim 설정은 별도 담당자가 병렬 처리한다.
- 기존 설정과 사용자 작업을 먼저 확인·백업한다. 다른 작업의 untracked 파일이나 Boulder 이력은 보존한다.
- 버전·출처를 고정하고 재설치·설정 적용·제거 방법을 문서화한다. 실제 설치된 의존성과 설정은 매뉴얼과 체크리스트에서 구분한다.
- QMD는 공개 저장소 매뉴얼만 색인한다. 로컬 임베딩·검색 모델 다운로드는 설치 범위에 포함한다. Volt 전체나 인증 자료를 자동 색인하지 않는다.
- Repomix는 공개 파일 allowlist와 비밀/임시 파일 제외 설정을 사용한다.
- Sidekick은 NES·mux를 끄고 기존 AI CLI 연결만 구성한다. tmux·Copilot 구독을 추가하지 않는다.
- LLM은 로컬 로그 기본 비활성, Promptfoo는 로컬 fixture provider 평가로 설치를 검증한다. 실제 유료 모델 호출·공급자 키 저장은 수행하지 않는다. 샘플 결과를 실제 모델 품질로 설명하지 않는다.
- MCP 클라이언트 전역 등록은 이번 작업에서 강제하지 않는다. QMD stdio 설정 예제와 적용·검증법은 제공한다.

## 검증 및 실행 증거

공유 가능한 결과는 `local/checks/ai-tools-results.json`, 상세 운영 문서는 `menual/ai-tools/`에 둔다. 설치 로그·개인 경로/인덱스·테스트 세션은 `.local-setup/` 또는 홈의 비공개 상태 디렉터리로 분리한다. 계획의 체크박스는 독립 검증 후에만 완료한다. 과정에서 차이가 발견되면 이 문서에 누적한다.
