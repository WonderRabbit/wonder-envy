# webp

- 설치 버전: 1.6.0
- 역할: Image format providing lossless and lossy compression for web images
- 분류: 의존성으로 설치

## 사용 방법

```sh
man cwebp
man dwebp
man gif2webp
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `cwebp`, `dwebp`, `gif2webp`, `img2webp`, `vwebp`, `webpinfo`, `webpmux`.

## 관리와 참고

설치 확인은 `brew info webp`. 업데이트는 필요할 때 `brew upgrade webp`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://developers.google.com/speed/webp/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/webp)
