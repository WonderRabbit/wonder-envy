# p11-kit

- 설치 버전: 0.26.5
- 역할: Library to load and enumerate PKCS#11 modules
- 분류: 의존성으로 설치

## 사용 방법

```sh
man p11-kit
man trust
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `p11-kit`, `trust`.

## 관리와 참고

설치 확인은 `brew info p11-kit`. 업데이트는 필요할 때 `brew upgrade p11-kit`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://p11-glue.github.io/p11-glue/p11-kit.html)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/p11-kit)
