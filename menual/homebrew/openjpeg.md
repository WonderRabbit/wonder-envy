# openjpeg

- 설치 버전: 2.5.4
- 역할: Library for JPEG-2000 image manipulation
- 분류: 의존성으로 설치

## 사용 방법

```sh
man opj_compress
man opj_decompress
man opj_dump
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `opj_compress`, `opj_decompress`, `opj_dump`.

## 관리와 참고

설치 확인은 `brew info openjpeg`. 업데이트는 필요할 때 `brew upgrade openjpeg`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.openjpeg.org/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/openjpeg)
