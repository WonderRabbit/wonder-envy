# libtasn1

- 설치 버전: 4.21.0
- 역할: ASN.1 structure parser library
- 분류: 의존성으로 설치

## 사용 방법

```sh
man asn1Coding
man asn1Decoding
man asn1Parser
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `asn1Coding`, `asn1Decoding`, `asn1Parser`.

## 관리와 참고

설치 확인은 `brew info libtasn1`. 업데이트는 필요할 때 `brew upgrade libtasn1`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.gnu.org/software/libtasn1/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/libtasn1)
