# little-cms2

- 설치 버전: 2.19.1
- 역할: Color management engine supporting ICC profiles
- 분류: 의존성으로 설치

## 사용 방법

```sh
man jpgicc
man linkicc
man psicc
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `jpgicc`, `linkicc`, `psicc`, `tificc`, `transicc`.

## 관리와 참고

설치 확인은 `brew info little-cms2`. 업데이트는 필요할 때 `brew upgrade little-cms2`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.littlecms.com/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/little-cms2)
