# herdr

- 설치 버전: 0.9.0
- 역할: Agent multiplexer that lives in your terminal
- 분류: 명시적 설치 도구

## 사용 방법

```sh
herdr
herdr integration status
# 현재 작업의 실제 디렉터리에서 시작
```

제공 명령: `herdr`.

## 관리와 참고

설치 확인은 `brew info herdr`. 업데이트는 필요할 때 `brew upgrade herdr`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://herdr.dev)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/herdr)
