# giflib

- 설치 버전: 6.1.3
- 역할: Library and utilities for processing GIFs
- 분류: 의존성으로 설치

## 사용 방법

```sh
man gifbuild
man gifclrmp
man giffix
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `gifbuild`, `gifclrmp`, `giffix`, `giftext`, `giftool`.

## 관리와 참고

설치 확인은 `brew info giflib`. 업데이트는 필요할 때 `brew upgrade giflib`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://giflib.sourceforge.net/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/giflib)
