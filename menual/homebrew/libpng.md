# libpng

- 설치 버전: 1.6.58
- 역할: Library for manipulating PNG images
- 분류: 의존성으로 설치

## 사용 방법

```sh
man libpng-config
man libpng16-config
man png-fix-itxt
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `libpng-config`, `libpng16-config`, `png-fix-itxt`, `pngfix`.

## 관리와 참고

설치 확인은 `brew info libpng`. 업데이트는 필요할 때 `brew upgrade libpng`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.libpng.org/pub/png/libpng.html)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/libpng)
