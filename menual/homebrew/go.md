# go

- 설치 버전: 1.27.1
- 역할: Open source programming language to build simple/reliable/efficient software
- 분류: 의존성으로 설치

## 사용 방법

```sh
go version
go help
# 프로젝트가 있을 때: go test ./...
```

제공 명령: `go`, `gofmt`.

## 관리와 참고

설치 확인은 `brew info go`. 업데이트는 필요할 때 `brew upgrade go`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://go.dev/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/go)
