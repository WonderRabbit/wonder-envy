# gh

- 설치 버전: 2.98.0, 2.100.0
- 역할: GitHub command-line tool
- 분류: 명시적 설치 도구

## 사용 방법

```sh
gh auth login
gh repo view
gh pr list
```

제공 명령: `gh`.

## 관리와 참고

설치 확인은 `brew info gh`. 업데이트는 필요할 때 `brew upgrade gh`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://cli.github.com/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/gh)
