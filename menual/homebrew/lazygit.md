# lazygit

- 설치 버전: 0.65.0
- 역할: Simple terminal UI for git commands
- 분류: 명시적 설치 도구

## 사용 방법

```sh
lazygit
# 또는 lg. 종료 q, 도움말은 화면의 키 안내 참고
```

제공 명령: `lazygit`.

## 관리와 참고

설치 확인은 `brew info lazygit`. 업데이트는 필요할 때 `brew upgrade lazygit`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://github.com/jesseduffield/lazygit/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/lazygit)
