# sevenzip

- 설치 버전: 26.03
- 역할: 7-Zip is a file archiver with a high compression ratio
- 분류: 명시적 설치 도구

## 사용 방법

```sh
7zz l archive.7z
7zz x archive.7z -ooutput
```

제공 명령: `7zz`.

## 관리와 참고

설치 확인은 `brew info sevenzip`. 업데이트는 필요할 때 `brew upgrade sevenzip`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://7-zip.org)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/sevenzip)
