# bash

- 설치 버전: 5.3.15
- 역할: Bourne-Again SHell, a UNIX command interpreter
- 분류: 명시적 설치 도구

## 사용 방법

```sh
bash script.sh
bash -n script.sh
```

제공 명령: `bash`, `bashbug`.

## 관리와 참고

설치 확인은 `brew info bash`. 업데이트는 필요할 때 `brew upgrade bash`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.gnu.org/software/bash/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/bash)
