# atuin

- 설치 버전: 18.22.0
- 역할: Improved shell history for zsh, bash, fish and nushell
- 분류: 명시적 설치 도구

## 사용 방법

```sh
atuin search --limit 10 "git"
# 대화형 셸에서 Ctrl-R: 검색, Tab/Enter: 편집할 명령 선택
```

제공 명령: `atuin`.

## 관리와 참고

설치 확인은 `brew info atuin`. 업데이트는 필요할 때 `brew upgrade atuin`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.
