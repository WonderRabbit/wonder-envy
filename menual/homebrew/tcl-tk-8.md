# tcl-tk@8

- 설치 버전: 8.6.18
- 역할: Tool Command Language
- 분류: 명시적 설치 도구

## 사용 방법

```sh
man critcl
man dtplite
man mkdoc
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `critcl`, `dtplite`, `mkdoc`, `nns`, `nnsd`, `nnslog`, `page`, `pt`, `tcldocstrip`, `tclsh`, `tclsh8.6`, `wish`, `wish8.6`.

## 관리와 참고

설치 확인은 `brew info tcl-tk@8`. 업데이트는 필요할 때 `brew upgrade tcl-tk@8`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.tcl-lang.org)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/tcl-tk@8)
