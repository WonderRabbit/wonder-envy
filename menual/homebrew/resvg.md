# resvg

- 설치 버전: 0.48.1
- 역할: SVG rendering tool and library
- 분류: 명시적 설치 도구

## 사용 방법

```sh
resvg input.svg output.png
```

제공 명령: `resvg`, `usvg`.

## 관리와 참고

설치 확인은 `brew info resvg`. 업데이트는 필요할 때 `brew upgrade resvg`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://github.com/linebender/resvg)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/resvg)
