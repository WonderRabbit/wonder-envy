# lz4

- 설치 버전: 1.10.0
- 역할: Extremely Fast Compression algorithm
- 분류: 의존성으로 설치

## 사용 방법

```sh
man lz4
man lz4c
man lz4cat
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `lz4`, `lz4c`, `lz4cat`, `unlz4`.

## 관리와 참고

설치 확인은 `brew info lz4`. 업데이트는 필요할 때 `brew upgrade lz4`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://lz4.github.io/lz4/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/lz4)
