# yazi

- 설치 버전: 26.9.1
- 역할: Blazing fast terminal file manager written in Rust, based on async I/O
- 분류: 명시적 설치 도구

## 사용 방법

```sh
y
# Enter로 열기, q로 종료. 텍스트는 nvim/LazyVim에서 편집
```

제공 명령: `ya`, `yazi`.

## 관리와 참고

설치 확인은 `brew info yazi`. 업데이트는 필요할 때 `brew upgrade yazi`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://yazi-rs.github.io)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/yazi)
