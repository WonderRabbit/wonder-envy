# pinentry

- 설치 버전: 1.3.3
- 역할: Passphrase entry dialog utilizing the Assuan protocol
- 분류: 의존성으로 설치

## 사용 방법

```sh
man pinentry
man pinentry-curses
man pinentry-tty
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `pinentry`, `pinentry-curses`, `pinentry-tty`.

## 관리와 참고

설치 확인은 `brew info pinentry`. 업데이트는 필요할 때 `brew upgrade pinentry`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.gnupg.org/related_software/pinentry/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/pinentry)
