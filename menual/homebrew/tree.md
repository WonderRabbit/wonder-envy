# tree

- 설치 버전: 2.3.2
- 역할: Display directories as trees (with optional color/HTML output)
- 분류: 명시적 설치 도구

## 사용 방법

```sh
tree -L 2
tree -a -I .git -L 2
```

제공 명령: `tree`.

## 관리와 참고

설치 확인은 `brew info tree`. 업데이트는 필요할 때 `brew upgrade tree`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.
