# oh-my-posh

- 설치 버전: 31.2.1
- 역할: Prompt theme engine for any shell
- 분류: 명시적 설치 도구

## 사용 방법

```sh
oh-my-posh version
# Fish 시작 시 자동 적용. 현재는 기본 테마 사용
```

제공 명령: `oh-my-posh`.

## 관리와 참고

설치 확인은 `brew info oh-my-posh`. 업데이트는 필요할 때 `brew upgrade oh-my-posh`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://ohmyposh.dev)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/oh-my-posh)
