# mdq

- 설치 버전: 0.10.0
- 역할: Like jq but for Markdown
- 분류: 명시적 설치 도구

## 사용 방법

```sh
mdq --help
mdq '#' README.md
```

제공 명령: `mdq`.

## 관리와 참고

설치 확인은 `brew info mdq`. 업데이트는 필요할 때 `brew upgrade mdq`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://github.com/yshavit/mdq)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/mdq)
