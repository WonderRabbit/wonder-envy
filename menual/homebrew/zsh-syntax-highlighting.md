# zsh-syntax-highlighting

- 설치 버전: 0.8.0
- 역할: Fish shell like syntax highlighting for zsh
- 분류: 명시적 설치 도구

## 사용 방법

```sh
# ~/.zshrc에서 초기화. 별도 실행 명령 없이 입력 문법을 색으로 표시
```

직접 실행보다 의존하는 앱·빌드 도구를 통해 사용한다. 프로젝트별 링크·include 옵션은 공식 문서에 따른다.

## 관리와 참고

설치 확인은 `brew info zsh-syntax-highlighting`. 업데이트는 필요할 때 `brew upgrade zsh-syntax-highlighting`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://github.com/zsh-users/zsh-syntax-highlighting)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/zsh-syntax-highlighting)
