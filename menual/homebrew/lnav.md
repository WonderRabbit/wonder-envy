# lnav

- 설치 버전: 0.14.1
- 역할: Curses-based tool for viewing and analyzing log files
- 분류: 명시적 설치 도구

## 사용 방법

```sh
lnav application.log
# SQL 모드: ;SELECT count(*) FROM all_logs;
# 종료 q / 도움말 ?
```

제공 명령: `lnav`.

## 관리와 참고

설치 확인은 `brew info lnav`. 업데이트는 필요할 때 `brew upgrade lnav`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://lnav.org/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/lnav)
