# autoconf

- 설치 버전: 2.73
- 역할: Automatic configure script builder
- 분류: 의존성으로 설치

## 사용 방법

```sh
autoconf --version
# configure.ac를 제공하는 소스 프로젝트에서 autoconf 실행
```

제공 명령: `autoconf`, `autoheader`, `autom4te`, `autoreconf`, `autoscan`, `autoupdate`, `ifnames`.

## 관리와 참고

설치 확인은 `brew info autoconf`. 업데이트는 필요할 때 `brew upgrade autoconf`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.gnu.org/software/autoconf/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/autoconf)
