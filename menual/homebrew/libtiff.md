# libtiff

- 설치 버전: 4.7.2
- 역할: TIFF library and utilities
- 분류: 의존성으로 설치

## 사용 방법

```sh
man fax2ps
man fax2tiff
man pal2rgb
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `fax2ps`, `fax2tiff`, `pal2rgb`, `ppm2tiff`, `raw2tiff`, `tiff2bw`, `tiff2pdf`, `tiff2ps`, `tiff2rgba`, `tiffcmp`, `tiffcp`, `tiffcrop`, `tiffdither`, `tiffdump`, `tiffinfo`, `tiffmedian`, `tiffset`, `tiffsplit`.

## 관리와 참고

설치 확인은 `brew info libtiff`. 업데이트는 필요할 때 `brew upgrade libtiff`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://libtiff.gitlab.io/libtiff/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/libtiff)
