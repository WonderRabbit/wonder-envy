# libgpg-error

- 설치 버전: 1.61
- 역할: Common error values for all GnuPG components
- 분류: 의존성으로 설치

## 사용 방법

```sh
man gpg-error
man gpg-error-config
man gpgrt-config
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `gpg-error`, `gpg-error-config`, `gpgrt-config`, `yat2m`.

## 관리와 참고

설치 확인은 `brew info libgpg-error`. 업데이트는 필요할 때 `brew upgrade libgpg-error`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.gnupg.org/related_software/libgpg-error/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/libgpg-error)
