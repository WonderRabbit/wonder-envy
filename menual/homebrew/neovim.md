# neovim

- 설치 버전: 0.12.5_1
- 역할: Ambitious Vim-fork focused on extensibility and agility
- 분류: 명시적 설치 도구

## 사용 방법

```sh
nvim README.md
# :w 저장 / :q 종료 / Space로 LazyVim 키 안내 / :Lazy 플러그인 관리
```

제공 명령: `nvim`.

## 관리와 참고

설치 확인은 `brew info neovim`. 업데이트는 필요할 때 `brew upgrade neovim`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://neovim.io/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/neovim)
