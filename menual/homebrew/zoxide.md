# zoxide

- 설치 버전: 0.10.0
- 역할: Shell extension to navigate your filesystem faster
- 분류: 명시적 설치 도구

## 사용 방법

```sh
z 프로젝트이름
zoxide query 프로젝트이름
```

제공 명령: `zoxide`.

## 관리와 참고

설치 확인은 `brew info zoxide`. 업데이트는 필요할 때 `brew upgrade zoxide`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [Homebrew 배포 정보](https://formulae.brew.sh/formula/zoxide)
