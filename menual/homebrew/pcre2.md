# pcre2

- 설치 버전: 10.47_1, 10.48
- 역할: Perl compatible regular expressions library with a new API
- 분류: 의존성으로 설치

## 사용 방법

```sh
man pcre2-config
man pcre2grep
man pcre2test
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `pcre2-config`, `pcre2grep`, `pcre2test`.

## 관리와 참고

설치 확인은 `brew info pcre2`. 업데이트는 필요할 때 `brew upgrade pcre2`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.pcre.org/)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/pcre2)
