# worktrunk

- 설치 버전: 0.77.0
- 역할: CLI for Git worktree management, designed for parallel AI agent workflows
- 분류: 명시적 설치 도구

## 사용 방법

```sh
wt list
wt switch <기존-브랜치>
# 새 작업: wt switch --create <새-브랜치>
```

제공 명령: `wt`.

## 관리와 참고

설치 확인은 `brew info worktrunk`. 업데이트는 필요할 때 `brew upgrade worktrunk`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.
