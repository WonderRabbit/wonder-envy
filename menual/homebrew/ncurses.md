# ncurses

- 설치 버전: 6.6
- 역할: Text-based UI library
- 분류: 의존성으로 설치

## 사용 방법

```sh
man captoinfo
man clear
man infocmp
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `captoinfo`, `clear`, `infocmp`, `infotocap`, `ncurses6-config`, `ncursesw6-config`, `reset`, `tabs`, `tic`, `toe`, `tput`, `tset`.

## 관리와 참고

설치 확인은 `brew info ncurses`. 업데이트는 필요할 때 `brew upgrade ncurses`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://invisible-island.net/ncurses/announce.html)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/ncurses)
