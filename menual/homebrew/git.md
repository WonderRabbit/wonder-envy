# git

- 설치 버전: 2.55.0
- 역할: Distributed revision control system
- 분류: 명시적 설치 도구

## 사용 방법

```sh
git status
git diff
git log --oneline -10
```

제공 명령: `git`, `git-cvsserver`, `git-receive-pack`, `git-shell`, `git-upload-archive`, `git-upload-pack`, `scalar`.

## 관리와 참고

설치 확인은 `brew info git`. 업데이트는 필요할 때 `brew upgrade git`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://git-scm.com)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/git)
