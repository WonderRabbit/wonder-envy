# libidn2

- 설치 버전: 2.3.8
- 역할: International domain name library (IDNA2008, Punycode and TR46)
- 분류: 의존성으로 설치

## 사용 방법

```sh
man idn2
# 제공 명령의 상세 옵션은 아래 공식 문서를 참조
```

제공 명령: `idn2`.

## 관리와 참고

설치 확인은 `brew info libidn2`. 업데이트는 필요할 때 `brew upgrade libidn2`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://www.gnu.org/software/libidn/#libidn2)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/libidn2)
