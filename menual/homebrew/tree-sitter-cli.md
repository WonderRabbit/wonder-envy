# tree-sitter-cli

- 설치 버전: 0.27.0
- 역할: Parser generator tool
- 분류: 명시적 설치 도구

## 사용 방법

```sh
tree-sitter --version
tree-sitter --help
# LazyVim Treesitter parser 빌드에 사용
```

제공 명령: `tree-sitter`.

## 관리와 참고

설치 확인은 `brew info tree-sitter-cli`. 업데이트는 필요할 때 `brew upgrade tree-sitter-cli`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://tree-sitter.github.io)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/tree-sitter-cli)
