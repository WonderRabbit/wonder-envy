# eza

- 설치 버전: 0.23.5
- 역할: Modern, maintained replacement for ls
- 분류: 명시적 설치 도구

## 사용 방법

```sh
eza -lah --git
eza --tree --level=2
```

제공 명령: `eza`.

## 관리와 참고

설치 확인은 `brew info eza`. 업데이트는 필요할 때 `brew upgrade eza`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://eza.rocks)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/eza)
