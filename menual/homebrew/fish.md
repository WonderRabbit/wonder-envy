# fish

- 설치 버전: 4.9.3
- 역할: User-friendly command-line shell for UNIX-like operating systems
- 분류: 명시적 설치 도구

## 사용 방법

```sh
fish
# Node/Java 작업은 dev로 Zsh에 진입
```

제공 명령: `fish`, `fish_indent`, `fish_key_reader`.

## 관리와 참고

설치 확인은 `brew info fish`. 업데이트는 필요할 때 `brew upgrade fish`로 진행한다. 의존성 패키지는 상위 도구의 요구를 확인하고 관리한다.

- [공식 홈페이지](https://fishshell.com)
- [Homebrew 배포 정보](https://formulae.brew.sh/formula/fish)
